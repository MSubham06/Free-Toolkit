# Free Toolkit

Small browser tools that do one job well. No install, no signup, no upload.

Each tool is a single HTML file. Download it and open it, or use the hosted link. Everything runs locally in your browser, so your files never leave your machine.

## Tools

### [Frame Grab](./frame-grab/)
Pull poster frames out of video files and save them as JPEGs, without installing ffmpeg. Samples six frames per clip, skips black ones automatically, and lets you scrub to any exact moment.

## Why

Most small tasks get solved by installing a command line tool you use twice, or by uploading private files to a stranger's server. Neither is great. These are built so you can download one file, use it offline forever, and delete it when you are done.
