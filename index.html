What this is · how to use it

The idea

Free Toolkit is a growing set of small web tools. Each one solves a single job I ran into while building things — and each one is written as one self-contained HTML file, with no frameworks, no build step, and no server.

Two ways to use a tool

Open tool loads it in a new tab and you start working straight away. Download asks you where to save that single file. Double-click it later and it opens in your browser and works exactly the same — on a plane, on college Wi-Fi, with the internet switched off entirely.

About your data

Whatever you drop into a tool — a video, a link, some text — is read and processed by your own browser. Nothing is uploaded, nothing is stored on a server, and there is no analytics script watching you. Close the tab and it is gone. You can verify all of it: press Ctrl + U on any tool and read the whole source.
